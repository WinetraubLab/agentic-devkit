# agentic-devkit

Tools for agentic development. The toolkit currently provides TDD linting and agent-review workflows for Python and TypeScript tests. Policy enforcement and skill template tooling are planned additions.

## Installation

```bash
python -m pip install git+https://github.com/WinetraubLab/agentic-devkit
```

## Tools

- [TDD linting](docs/tdd/README.md): test quality checks, review packets, review proof, and project setup.
- [GitHub Actions review proof](docs/workflows/github-actions.md): CI validation of committed reviews.

```bash
agentic-devkit tdd --help
```
